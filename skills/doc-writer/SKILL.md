# Document Writer

Create professional long-form content with research and structure.

## Document Types

### Technical Documentation
- API reference, setup guides, architecture docs
- Structure: Overview → Prerequisites → Steps → Troubleshooting → Reference

### User Guide
- End-user facing, step-by-step
- Structure: Getting Started → Core Features → Advanced → FAQ

### Whitepaper
- Thought leadership, data-driven
- Structure: Abstract → Problem → Analysis → Solution → Evidence → Conclusion

### Case Study
- Client success story
- Structure: Challenge → Approach → Solution → Results → Testimonial

### SOP (Standard Operating Procedure)
- Internal process documentation
- Structure: Purpose → Scope → Responsibilities → Steps → Exceptions

## Process
1. **Research**: Gather context via deep-research if needed
2. **Outline**: Create structured outline, confirm with user
3. **Draft**: Write section by section
4. **Review**: Check for accuracy, consistency, completeness
5. **Format**: Apply appropriate formatting (markdown, HTML, or PDF via /pdf-gen)

## Rules
- Write for the target audience (technical vs non-technical)
- Include code examples for technical docs
- Use tables for comparisons and reference data
- Add a TL;DR at the top for long documents
- Include sources/references where applicable
