## Gate
- [ ] Every P0 feature has at least one user story.
- [ ] Every user story has atomic, measurable acceptance criteria.
- [ ] Every acceptance criterion has an ID and one verification method.
- [ ] Traceability covers every P0 feature.
- [ ] No feature is described only as simple, clean, modern, or works.
- [ ] User confirms PRD before TRD begins.
