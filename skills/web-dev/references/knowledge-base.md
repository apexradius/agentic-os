## §framework-architecture
- **React** = component library; historic footguns are referential stability + `useEffect` dependency arrays; React 19.2's stable **React Compiler** auto-optimizes rendering, removing manual `useMemo`/`useCallback`; adds `Activity` (state-preserving `display:none`) and `useEffectEvent` [WD 55a2dcf1][WD f313c68a].
- **Next.js** = most popular React meta-framework; optimal for full-stack monolith, SSR, SEO; unifies FE/BE via server components + server actions; bespoke runtime for routing/middleware/image-opt/ISR [WD f313c68a][WD b5bb0bf6].
- **Vue** = progressive, incrementally adoptable, gentler curve than Angular; Options API (rigid objects) vs Composition API (Vue 3, React-like reactive refs) [WD 64da3bdb].
- **Svelte 5** = compiler-driven, performant; **Astro** = SSR/SSG meta-framework for content/Jamstack; **TanStack Start** = DX-first full-stack React, doc-level SSR + streaming + type-safe server fns via TanStack Router; **Ripple** = late-2025 compiler framework, JSX with in-template control flow + `track()` reactivity [WD b5bb0bf6][WD 7147ce06][WD 403351b0].
- **Rendering strategies:** CSR/SPA — whole UI+routing bundled to client, snappy post-load but large initial JS + poor SEO; SSR — server renders full HTML per request, faster FCP + crawlable, needs server runtime; SSG pre-renders at build, ISR updates static pages in background [WD f313c68a][WD b5bb0bf6]. *(Gap: sources don't detail ISR/SSG low-level tradeoffs.)*
- **Next.js App Router** = file-system routing: `app/tickets/new/page.tsx`→`/tickets/new`; `[id]` = dynamic param (from `params` prop); `(group)` parens omitted from URL, used to apply separate sub-layouts (e.g. auth vs dashboard shells) [WD 45a4f7ee][WD 98748209].

## §components-state
- Split state: **component-level** (local, e.g. `isOpen`) vs **global/app-level** (carts, auth) [WD 98748209][WD 9f3f68ca].
- `useState` = local reactive state; `useEffect` = sync with external systems, but misconfigured deps cause infinite loops / duplicate calls (real outages); prefer `useEffectEvent` (19.2) to run effect logic without adding to dep array [WD a8cc87e1][WD 55a2dcf1].
- **Prop drilling** solved by **Context API** (simple global: theme/session) or **Zustand/Redux** (larger apps). Clean pattern: provider wraps `children`, pass state+setters via `value`, export a custom `useX` hook over `useContext`. In RSC apps, isolate the provider in an `AuthWrapper` client component so the server layout doesn't become a client component [WD 98748209][WD 45a4f7ee].
- **Composition/slots:** Vue `<slot>` and native Web Component `<slot>` project parent markup into a wrapper template; Web Component slots project Light DOM into Shadow DOM enabling progressive enhancement [WD 64da3bdb][WD e09dce57].
- **DRY extraction:** AI codegen violates DRY by dumping all UI inline on one page = instant tech debt; extract repeated layout into standalone files, but co-locate single-use components (e.g. `ticket-form.tsx` beside its `page.tsx`) rather than a global `components/` dump [WD 40a735f8][WD 45a4f7ee].
- **Vue SFC** = `.vue` with `<script setup>` / `<template>` (directives `v-if`/`v-for`/`:`/`@`) / `<style scoped>`; `ref` (primitives+objects, `.value` in JS) vs `reactive` (objects only, no reassignment) [WD 64da3bdb][WD 0cdc2ecd]. *(Gap: signals not covered beyond Ripple's `track`.)*

## §styling-responsive
- **Modern CSS reset:** `100svh` not `vh`/`dvh` for mobile hero (dvh triggers address-bar repaints); `scrollbar-gutter: stable` on `html` prevents nav jump; `interpolate-size: allow-keywords` animates to `auto`; `text-wrap: balance` (headings) / `pretty` (paragraphs); `aspect-ratio`+`object-fit: cover`; `isolation: isolate` for clean stacking contexts instead of z-index wars [WD 098ef876][WD 02c7317a][WD a3fb5ab0].
- **Layout:** Flexbox = 1-D (row *or* column); Grid = 2-D, keeps sizing on parent so children need no explicit widths. Media-query-free responsive grid: `repeat(auto-fit, minmax(min(300px,100%), 1fr))` — the `min(…,100%)` clamp prevents overflow on narrow screens; `auto-fit` collapses empty tracks (stretches items), `auto-fill` keeps ghost columns (stable widths for filtered lists) [WD 7e5a9d8d][WD a0f34d4c][WD 7fade1c2].
- **Container queries:** `container-type: inline-size` + `100cqi` background keeps gradient progress bars from squishing; `container-type: scroll-state` + `@container scroll-state(stuck: top)` does sticky-state styling with no scroll JS [WD 12f59858][WD 330d145b].
- **CSS variables/color:** relative-color syntax `hsl(from var(--c) h s l / .5)`; space-separated is the modern standard; register custom props with `@property` (typed) to animate them. Native CSS nesting needs no Sass but compiles via `:is()` → inherits the *most specific* selector's specificity (ID trap), and cannot concatenate BEM suffixes (`&__child` invalid) [WD abd82d45][WD 7ae75317].
- **Dark mode:** declare `color-scheme: light dark` on root (swaps UA form/scrollbar styles); `light-dark(a,b)` for single-line overrides without media queries [WD 35239bba].

## §accessibility-forms (implementation patterns)
- **Semantic HTML** = free accessibility tree; use `<header>/<main>/<aside>/<section>/<footer>` not div soup [WD f313c68a][WD 9ba19401].
- **ARIA:** `aria-label` for icon-only controls; `aria-describedby` for field help; `aria-live="polite"` announces toasts/errors without interrupting (`assertive` interrupts); `aria-hidden="true"` on decorative SVGs; live-region node stays in DOM, text swaps to trigger announce [WD d3d5ba8d][WD 061321af].
- **Focus:** never blanket `outline:none`; use `:focus-visible` (ring on keyboard, none on mouse); trap focus in modals; `autofocus` the primary field, not the close button [WD 7e5a9d8d][WD d3d5ba8d].
- **Forms as code:** `<label htmlFor>`↔input `id`; validate on **blur** not while typing, clear the error on next `input`; render only the **first** validity error, not a wall; visually-hidden spans for text-free controls; alt text updates with dynamic state (configurators) [WD e09dce57][WD d7bf620c][WD 9ba19401].
- **Server actions (Next/React):** `"use server"` fns bound to `<form action>`, read native `FormData.get('name')` — no API route. `useActionState` (R19) / `useFormState` (R18, from `react-dom`) — wrapping shifts action signature to `(prevState, formData)`; return `{success, message}`, watch via `useEffect`→toast (`sonner`/`react-toastify`) or `router.push`; reset uncontrolled forms via `useRef().reset()` [WD 98748209][WD 45a4f7ee][WD 9f3f68ca].
- **Zod + React Hook Form:** `z.object()`, use `.min(1)` (not deprecated `.required()`), chain `.email()`; wire via `zodResolver`, infer types `z.infer<typeof schema>`, pre-fill edits via `defaultValues`. Native constraint validation (`required`/`pattern`/`min`) works if you drop `noValidate` [WD a385b2c4][WD e09dce57]. Vue: `v-model` two-way bind, `@submit.prevent`, `v-if="error"` [WD 0cdc2ecd].

## §data-integration
- Native promise-based `fetch` (browsers/Node/Bun) removes need for Axios [WD 31508c14]. **TanStack Query** replaces manual `useState`+`useEffect` for server state — auto fetch/cache/background-update [WD 2a17d2ee]. Backend-agnostic pattern: React Admin's **Data Provider** adapter normalizes UI queries to REST *or* GraphQL [WD 5ba90643].
- **RSC/server actions** fetch straight from DB in server components; `revalidatePath('/')` purges cache after mutation. TanStack Start route `loader` pre-loads data before render [WD 0cb69fa8][WD 9f3f68ca][WD 7147ce06].
- **ORMs (parameterized = no SQL injection):** **Prisma** — `schema.prisma`, `prisma migrate dev` + `generate`; guard the Next dev hot-reload connection-pool exhaustion with a global cached client. **Drizzle** — TS-first schema, `drizzle-kit generate/migrate`, infer `$inferInsert`/`$inferSelect`, SQL-like builder `.select().from().where(eq()).orderBy()` [WD 9f3f68ca][WD 0cdc2ecd]. **Sentry** captures exceptions + session replays [WD 45a4f7ee].

## §failures
- **Vibe coding** = prompt, accept diffs blind, paste errors until they vanish → **45% of AI code fails security tests** (Veracode: XSS/SQLi/access-control); AI PRs **18% larger**, **10.83 vs 6.45** issues/PR (Code Rabbit); hallucinated/outdated deps; erodes team knowledge (nobody can fix the 2 AM outage); beginners become "PM for an AI," can't debug [WD d1384a7f][WD 40a735f8][WD b2869176].
- **Security:** CVE-2025-55182 = 10.0 RCE in React Server Components Flight protocol (poisoned payloads, no auth) — audit/update RSC deps; Axios supply-chain RAT (2026, `plain-crypto-js` post-install dropper stealing env keys); never store plain-text passwords (hash+salt); never concatenate SQL (use ORM) [WD d6806f34][WD 31508c14][WD 4c95d2bd].
- **Over-engineering:** premature microservices/Docker/auth before a homepage kills momentum — start "one repo, one DB, one framework," ship an MVP; don't juggle 15–20 projects or over-plan for months [WD 0c7f078e][WD bf7650d4].
- **CSS fouls:** redundant `width:100%`/`100vw` → horizontal overflow; rigid fixed `height` breaks on wrap/i18n (use `min-height`/`auto`); `outline:none` kills keyboard nav (use `:focus-visible`); `display:flex/grid` directly on `<dialog>` keeps it visible when closed (scope to `dialog[open]`); `100vh`/`dvh` mobile repaints (use `100svh`) [WD 7e5a9d8d][WD d3d5ba8d][WD 098ef876].
